## Pipeline extension tables (Sprint 52–67)

This section documents the tables that grew out of the AI pipeline
after Sprint 52. They all live alongside the core 6 tables above and
share the same `opportunities.id` foreign key where applicable.

### opportunity_validations (Sprint 52)
4-dimension validation score produced by `validation.service.ts`:
market, problem, solution, moat. Total 0–100. Gates downstream
generation when `score >= 70`.

Fields: `id`, `opportunity_id`, `market_score`, `problem_score`,
`solution_score`, `moat_score`, `total_score`, `reasoning`, `created_at`.

### opportunity_evidence (Sprint 53)
Market evidence generated by `evidence.service.ts`. Supports
`score >= 70` opportunities with concrete proof points: search
trends, Reddit mentions, GitHub stars, competitor data, expert
quotes.

Fields: `id`, `opportunity_id`, `source_type`, `source_url`,
`summary`, `confidence`, `created_at`.

### opportunity_forecasts (Sprint 54)
Growth / momentum / pressure dimensions produced by `forecast.service.ts`.

Fields: `id`, `opportunity_id`, `growth_score`, `momentum_score`,
`pressure_score`, `forecast_score`, `time_horizon`, `reasoning`,
`created_at`.

### market_intelligence (Sprint 55)
Six external signal scores: market_size, market_growth, timing,
competition, regulatory, technology_maturity.

Fields: `id`, `opportunity_id`, `market_size_score`,
`market_growth_score`, `timing_score`, `competition_score`,
`regulatory_score`, `technology_maturity_score`, `overall_score`,
`signals_json`, `created_at`.

### startup_scores (Sprint 56)
Seven-dimension VC score (team, market, product, traction, defensibility,
business_model, timing). Triple-gate before downstream generation
(score >= 70 + market_intel >= 60 + forecast >= 60).

Fields: `id`, `opportunity_id`, `team_score`, `market_score`,
`product_score`, `traction_score`, `defensibility_score`,
`business_model_score`, `timing_score`, `overall_score`,
`confidence`, `created_at`.

### venture_reports (Sprint 57)
17-section venture research report (problem, market, solution, GTM,
competition, team, financial projections, risks). Gate: startup_score >= 80.

Fields: `id`, `opportunity_id`, `sections_json`, `executive_summary`,
`created_at`.

### investment_memos (Sprint 58)
Concise YC/Sequoia/a16z-style memo (1–2 pages). Gate: startup_score >= 85.
Triggers "💰 Investor Ready" alert on STRONG BUY.

Fields: `id`, `opportunity_id`, `title`, `recommendation`,
`confidence`, `content_markdown`, `content_json`, `created_at`.

### investment_committees (Sprint 61, 67)
5-agent committee decision (Market Analyst, Product Partner,
Financial Partner, Technical Partner, VC Partner). Aggregates to
Strong Buy / Buy / Watch / Reject.

Fields: `id`, `opportunity_id`, `final_decision`, `committee_score`,
`reasoning`, `created_at`.

### committee_votes (Sprint 61, 67)
Per-agent votes inside each committee.

Fields: `id`, `committee_id`, `agent_role`, `vote`, `score`,
`reasoning`, `created_at`.

### opportunity_backtests (Sprint 59)
Predicted vs actual scores recorded after a future evaluation date.
Drives accuracy metrics for the Backtesting Engine.

Fields: `id`, `opportunity_id`, `predicted_score`, `actual_score`,
`prediction_delta`, `accuracy`, `evaluation_date`, `created_at`.

### portfolio_items (Sprint 60)
User-tracked opportunities with health_score, alert thresholds, and
archived flag.

Fields: `id`, `user_id`, `opportunity_id`, `notes`, `health_score`,
`alert_threshold`, `archived`, `created_at`.

### research_jobs / research_sources / research_logs (Sprint 62)
Autonomous research agent state. `research_jobs` is the parent row;
`research_sources` records per-adapter (reddit / github / hackernews
/ producthunt / rss) results; `research_logs` is the append-only
execution log.

### venture_projects / venture_canvas / venture_gtm / venture_mvp (Sprint 63)
AI Venture Studio Generator output. `venture_projects` is the parent
row; the others are 1:1 detail tables (canvas, go-to-market, MVP).

### financial_models / financial_projections / unit_economics / break_even_analysis (Sprint 64)
Financial Projection Engine. `financial_models` is the parent row;
`financial_projections` holds month-by-month forecasts; `unit_economics`
records LTV / CAC / payback; `break_even_analysis` captures the
time-to-breakeven calculation.

### pain_point_embeddings (Sprint 37, resized Sprint 68)
Vector embeddings for clustering. Stores 1024d vectors (NVIDIA
`nv-embedqa-e5-v5`) and an ivfflat cosine index for fast ANN search.

Fields: `id`, `pain_point_id`, `embedding (vector(1024))`, `model`,
`created_at`. Match function: `public.match_pain_points(vector, float, int)`.

## User-facing tables (Sprint 47+)

### profiles
User profile with `role` column (`"authenticated" \| "admin"`) for
future server-side admin gating (currently enforced in UI only).

Fields: `id` (= Supabase Auth UID), `email`, `full_name`, `avatar_url`,
`role`, `stripe_customer_id`, `subscription_status`, `created_at`,
`updated_at`.

### saved_opportunities
User favorites.

Fields: `id`, `user_id`, `opportunity_id`, `created_at`.

### watchlists
Auto-monitoring lists (each tracks N opportunities + alert thresholds).

Fields: `id`, `user_id`, `name`, `description`, `alert_threshold`,
`created_at`.

### alerts
Real-time notifications (saved_opportunity changes, committee
decisions, forecast alerts, weekly digest).

Fields: `id`, `user_id`, `type`, `title`, `body`, `link`, `read`,
`created_at`.

### weekly_digests
Weekly email digest records (`queued` → `sent` lifecycle).

Fields: `id`, `user_id`, `week_of`, `status`, `sent_at`, `content_json`.

### notification_settings
Per-user notification preferences (channel, frequency, opt-outs).

Fields: `id`, `user_id`, `email_digest`, `email_alerts`, `inapp_alerts`,
`updated_at`.
